:math:`F_{n} = F_{n - 1} + F_{(n - 2_{)}}`. It can also be expressed in
*closed form:*

:math:`F_{n} = \left\lfloor {\frac{1}{\sqrt{5}}\phi^{n}} \right\rceil,\quad\phi = \frac{1 + \sqrt{5}}{2}`
